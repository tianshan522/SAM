# SAM 成人到婴儿年龄变换 —— 训练前准备说明

本文档覆盖从环境搭建到评估的完整流程。

## 0. SAM 的训练范式（必读）

SAM 采用**无配对的自监督训练**，不需要"同一个人的成人照 + 婴儿照"配对数据：

1. 输入：任意人脸图片 + 第 4 通道指定目标年龄
2. DEX 年龄分类器估算输入年龄 & 监督输出年龄接近目标
3. ArcFace ID Loss 保持输入与输出的身份一致性
4. LPIPS / L2 保持图像质量，Cycle Loss 保证变换可逆

因此，训练数据只需要**大量对齐好的人脸图片**（如 FFHQ），模型自动学习任意年龄之间的转换。

> **之前文档的"source/target 配对"方案存在根本性问题：**
> `AgingTransforms` 中 `transform_source = None`，导致 `ImagesDataset` 的 `__getitem__` 将 source 替换为 target（`from_im = to_im`），成人 source 图片从未被使用。即使修复此 bug，配对方案也与 SAM 的 aging loss + cycle loss 训练设计冲突。

## 4. 数据集准备

### 4.1 FFHQ 数据集（推荐）

FFHQ（Flickr-Faces-HQ）包含 70,000 张已对齐的 1024x1024 人脸图片，覆盖各年龄段。

下载 256x256 版本（约 15 GB）后放入 `workspace/datasets/ffhq/images256x256/`。

从中划分一部分作为测试集放入 `workspace/datasets/ffhq/test/`，例如留出最后 2,000 张。

### 4.2 自己收集的人脸图片

如果使用自己收集的图片，**必须先做 FFHQ 风格的人脸对齐**：

```bash
python scripts/align_all_parallel.py \
    --root_path=<原始图片目录> \
    --num_threads=4
```

对齐后的图片保存在 `<原始图片目录>_crops/`，分辨率 256x256。

注意：对齐脚本依赖 dlib（`pip install dlib`）和 `shape_predictor_68_face_landmarks.dat`。

### 4.3 配置数据路径

编辑 `configs/paths_config.py`，修改 `FFHQ_ROOT` 或直接修改 `dataset_paths`：

```python
dataset_paths = {
    "ffhq": "实际的FFHQ训练集路径",
    "celeba_test": "实际的测试集路径",
}
```

## 5. 推理验证（Baseline）

在训练前，先用官方预训练模型跑推理，验证环境正确并获取 baseline：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\local\quick_infer.ps1
```

默认配置在脚本顶部可以修改：
- `$DefaultInputPath` — 输入图片路径
- `$DefaultTargetAge` — 目标年龄（"1" 表示 1 岁婴儿）
- `$DefaultOutputDir` — 输出目录

也可以通过命令行参数指定：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\local\quick_infer.ps1 `
    -InputPath "你的图片路径" `
    -TargetAge "0,1,3,5" `
    -OutputDir "workspace\runs\baseline"
```

## 6. 训练

### 6.1 本地训练

推荐使用快捷脚本启动，所有可调参数集中在脚本顶部的配置区：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\local\quick_train.ps1
```

或手动运行（从官方预训练模型微调）：

```bash
python scripts/train.py \
    --dataset_type=ffhq_aging \
    --exp_dir=experiments/adult_to_baby_finetune \
    --checkpoint_path=pretrained_models/sam_ffhq_aging.pt \
    --workers=0 \
    --batch_size=2 \
    --test_batch_size=2 \
    --test_workers=0 \
    --val_interval=2500 \
    --save_interval=5000 \
    --max_steps=50000 \
    --start_from_encoded_w_plus \
    --id_lambda=0.1 \
    --lpips_lambda=0.1 \
    --lpips_lambda_aging=0.1 \
    --lpips_lambda_crop=0.6 \
    --l2_lambda=0.25 \
    --l2_lambda_aging=0.25 \
    --l2_lambda_crop=1 \
    --w_norm_lambda=0.005 \
    --aging_lambda=5 \
    --cycle_lambda=1 \
    --input_nc=4 \
    --target_age=uniform_random \
    --use_weighted_id_loss
```

注意：本地 RTX 5060 (8GB) 只能用 batch_size=2，训练 50k 步约需 5.8 天。建议用于短期验证，正式训练使用远程平台。

关键超参数说明：

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `--aging_lambda` | 5 | 年龄损失权重。增大使婴儿效果更明显，但可能牺牲身份保持 |
| `--id_lambda` | 0.1 | 身份损失权重。增大可提升身份保持度 |
| `--cycle_lambda` | 1 | 循环一致性权重。确保变换可逆 |
| `--checkpoint_path` | — | 从预训练模型微调而非从头训练 |
| `--max_steps` | 50000 | 微调不需要跑满 500k 步 |
| `--target_age` | uniform_random | 在 0-100 之间均匀随机采样目标年龄 |

### 6.2 远程平台训练

```bash
python scripts/local/dlpflow_train.py
```

使用前确保 `dlpctl` 已安装并登录，远端环境有 Python、CUDA 和所需依赖。

### 6.3 监控训练

训练日志保存在 `experiments/<exp_name>/logs/`，可用 TensorBoard 查看：

```bash
tensorboard --logdir=experiments/adult_to_baby_finetune/logs
```

关注的指标：
- `loss_aging_real` — 年龄损失，越低说明年龄变换越准确
- `loss_id_real` — 身份损失，越低说明身份保持越好
- `id_improve_real` — 身份改善度，正值说明生成图比输入更接近目标

## 7. 评估

### 7.1 推理

用训练好的模型生成结果：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\local\quick_infer.ps1 `
    -CheckpointPath "experiments\adult_to_baby_finetune\checkpoints\best_model.pt" `
    -InputPath "测试图片目录" `
    -TargetAge "0,1,3,5" `
    -OutputDir "workspace\runs\eval_output"
```

### 7.2 量化评估

```bash
python scripts/local/evaluate.py \
    --generated_dir workspace/runs/eval_output/inference_results/1 \
    --source_dir <原始输入图片目录> \
    --target_age 1
```

输出三个指标：
- **FID**（Frechet Inception Distance）：衡量生成图与真实图的分布距离，越低越好
- **身份保持度**（ArcFace Cosine Similarity）：输入成人脸与输出婴儿脸的特征相似度，越高越好
- **年龄准确度**（DEX MAE）：生成图的预测年龄与目标年龄的绝对误差，越低越好

### 7.3 Baseline 参考值

使用官方 `sam_ffhq_aging.pt` 模型、目标年龄 1 的单样本测试：
- 身份保持度: 0.63
- 预测年龄: 8.0（MAE = 7.05）

训练后应在更大测试集上对比这些指标。

## 8. 调优建议

如果**婴儿效果不够明显**（年龄 MAE 偏高）：
- 增大 `--aging_lambda`（如 8 或 10）
- 减小 `--use_weighted_id_loss` 的影响（此选项在年龄变化大时降低 ID loss 权重）

如果**身份保持不好**（cosine similarity 偏低）：
- 增大 `--id_lambda`（如 0.2 或 0.5）
- 增大 `--lpips_lambda_crop`

如果**图像质量差**（FID 偏高）：
- 增大 `--lpips_lambda` 和 `--l2_lambda`
- 确保训练数据质量好且对齐正确
