## 2. 必须准备的文件

### 2-A. 预训练模型（需放在 `pretrained_models/` 目录）

下载地址均在 Google Drive，可用脚本一键下载：

```bash
bash scripts/local/download_required_assets.sh
```

脚本会自动下载以下文件：

| 文件名 | 说明 |
|--------|------|
| `pretrained_models/sam_ffhq_aging.pt` | **主模型**，SAM 在 FFHQ 上的预训练权重，微调的起点 |
| `pretrained_models/psp_ffhq_encode.pt` | pSp 编码器，用于提取 W+ 潜码 |
| `pretrained_models/stylegan2-ffhq-config-f.pt` | StyleGAN2 生成器权重 |
| `pretrained_models/model_ir_se50.pth` | IR-SE50，用于 ID Loss（ArcFace） |
| `pretrained_models/dex_age_classifier.pth` | DEX VGG 年龄分类器，用于 Aging Loss |
| `shape_predictor_68_face_landmarks.dat` | 人脸关键点检测（放在仓库根目录） |

> 如果 Google Drive 无法访问，需要手动下载后放到对应路径。

---

### 2-B. 训练数据集（需自行拷贝）

数据集存放路径（两个目录都要有）：

```
SAM/
└── workspace/
    └── datasets/
        └── humans_aligned/
            ├── train/   ← 训练集（256×256 PNG/JPG 人脸图片）
            └── test/    ← 测试集（256×256 PNG/JPG 人脸图片，几十张即可）
```

**要求：**
- 图片分辨率：256×256（或更大，会自动 resize）
- 格式：JPG 或 PNG 均可
- 训练集建议数量：5000 张以上
- 测试集：50~200 张即可

## 3. 填写配置文件

在仓库根目录新建 `scripts/local/dlp_config.py`（此文件已加入 `.gitignore`，不会泄漏账号）：

```python
# scripts/local/dlp_config.py

# ── 账号信息 ──────────────────────────────────────────────────
DLP_USERNAME = "你的DLP用户名"      # 例如 "yc1"
DLP_PASSWORD = "你的DLP密码"

# ── GPU 配置 ──────────────────────────────────────────────────
DLP_GPU_TYPE = "3090"     # GPU 型号（如 3090、A100）
DLP_GPU_NUM  = 1          # GPU 数量

# ── 云端路径 ──────────────────────────────────────────────────
# 代码和数据在云端 NFS 上的 Linux 绝对路径
# 挂载云盘后执行 ls 查看你的文件夹名，再填写
CLOUD_REPO_DIR = "/cloud/tmp/yc/SAM"   # ← 根据实际情况修改
```

## 4. 在 Mac 上挂载云盘并同步文件

### 4-1. 挂载 NFS

```bash
# 创建挂载点
sudo mkdir -p ~/Documents/cloud_yc

# 挂载 NFS（注意路径是 /cloud/tmp/yc，不是 yc1）
sudo mount -t nfs -o nolock,resvport,rw 172.30.2.93:/cloud/tmp/yc ~/Documents/cloud_yc

# 查看云盘内容，确认你的文件夹
ls ~/Documents/cloud_yc
```

> **注意**：挂载路径是 `/cloud/tmp/yc`（不是 `yc1`），以 `showmount -e 172.30.2.93` 输出为准。

---

### 4-2. 同步代码到云端

```bash
# 在 SAM 仓库根目录执行
# 同步代码（排除不需要上传的文件）
rsync -av --progress \
  --exclude='.conda' \
  --exclude='.git' \
  --exclude='experiments' \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  --exclude='scripts/local/dlp_config.py' \
  /path/to/local/SAM/ \
  ~/Documents/cloud_yc/SAM/
```

> 将 `/path/to/local/SAM/` 替换为你本地的仓库路径，例如 `/Users/你的用户名/SAM/`

---

### 4-3. 同步训练数据集到云端

数据集文件一般较大，单独同步：

```bash
rsync -av --progress \
  /path/to/local/humans_aligned/ \
  ~/Documents/cloud_yc/SAM/workspace/datasets/humans_aligned/
```

---

### 4-4. 同步预训练模型到云端

```bash
rsync -av --progress \
  /path/to/local/SAM/pretrained_models/ \
  ~/Documents/cloud_yc/SAM/pretrained_models/

# 人脸关键点文件单独同步
cp /path/to/local/SAM/shape_predictor_68_face_landmarks.dat \
   ~/Documents/cloud_yc/SAM/
```

---

### 4-5. 在云端创建 dlp_config.py

此文件不在 git 中，需要手动在云端创建：

```bash
cat > ~/Documents/cloud_yc/SAM/scripts/local/dlp_config.py << 'EOF'
DLP_USERNAME = "你的DLP用户名"
DLP_PASSWORD = "你的DLP密码"
DLP_GPU_TYPE = "3090"
DLP_GPU_NUM  = 1
CLOUD_REPO_DIR = "/cloud/tmp/yc/SAM"
EOF
```

## 5. 登录 DLP 平台并验证环境

### 5-1. 准备一个轻量的 conda 环境（仅用于提交任务）

```bash
conda create -n sam-dlp python=3.11 -y
```

### 5-2. 安装 dlpctl

```bash
conda run -n sam-dlp pip install \
  -i http://pypi.truesightai.com/simple \
  --trusted-host pypi.truesightai.com \
  dlpctl
```

### 5-3. 登录

```bash
conda run -n sam-dlp dlpctl login -u 你的用户名 -p 你的密码
```

### 5-4. 提交 Smoke Test（验证 GPU 环境）

```bash
cd /path/to/SAM
conda run -n sam-dlp python scripts/local/cloud/trial/smoke_test.py
```

## 6. 提交训练任务

### 6-A. 快速验证（500步，约 10 分钟，先用这个验证流程是否通畅）

```bash
conda run -n sam-dlp python scripts/local/cloud/trial/quick_train.py
```

**脚本会实时打印训练日志，可以看到每步的 loss 变化。**

---

### 6-B. 正式训练（50000步，约数小时）

确认快速验证没有报错后，提交正式训练：

```bash
conda run -n sam-dlp python scripts/local/cloud/train.py
```

**关键训练参数：**

| 参数 | 值 | 说明 |
|------|-----|------|
| `target_age` | `baby_biased` | 60% 概率采样 0-5 岁，强化婴儿脸生成 |
| `aging_lambda` | `8.0` | 年龄损失权重（越大婴儿效果越明显） |
| `max_steps` | `50000` | 总训练步数 |
| `save_interval` | `5000` | 每 5000 步保存一次 checkpoint |
| `val_interval` | `2500` | 每 2500 步做一次验证并生成样图 |

## 常见问题

**Q: 提交任务报错 `找不到 dlp_config.py`**  
A: 确认 `scripts/local/dlp_config.py` 存在，且 `CLOUD_REPO_DIR` 已填写正确的云端路径。

**Q: 云端训练报错 `No such file or directory`（找不到训练脚本或模型）**  
A: 代码/模型没有同步到云端。重新执行第 4 节的 `rsync` 命令，确认文件已上传。

**Q: 训练报错 `No images found in dataset`**  
A: 数据集路径不对或为空。检查云端 `workspace/datasets/humans_aligned/train/` 目录下是否有图片。

**Q: NFS 挂载断开**  
A: 重新执行 `sudo mount -t nfs -o nolock,resvport,rw 172.30.2.93:/cloud/tmp/yc ~/Documents/cloud_yc`

**Q: 任务提交后看不到日志**  
A: 脚本会自动轮询并打印日志。如果手动中断了脚本，可以用以下命令查看历史日志：  
```bash
conda run -n sam-dlp dlpctl logs task <task-name>
```
